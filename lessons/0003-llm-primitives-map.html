The LLM Primitives Map

The complete top-down map of what an Applied AI Engineer interview can test. One session per primitive cluster.

Tier 1 — How LLMs Think (Model Internals)

The "how does it actually work" questions. Interviewers use these to filter for depth.

Attention & Architecture

self-attention (Q/K/V) causal / masked attention multi-head attention KV cache positional encoding (RoPE, ALiBi) prefill vs. decode phase encoder-only vs decoder-only MoE (Mixture of Experts) Flash Attention GQA / MQA

Tokenization

BPE (Byte-Pair Encoding) token vs. character vs. word why arithmetic fails at token level context window = tokens, not chars

Scaling Laws

Chinchilla scaling compute-optimal training emergent abilities
Tier 2 — How LLMs Learn (Training & Alignment)

The "how did it get good at following instructions" questions.

Pre-training

next-token prediction / cross-entropy loss data curation at scale parallelism (data, tensor, pipeline) mixed-precision (BF16, FP8)

Alignment

RLHF (reward model, PPO, KL constraint) DPO SFT / instruction tuning RLAIF Constitutional AI reward hacking / Goodhart's Law

Fine-tuning & PEFT

LoRA (rank, alpha, target modules) QLoRA prefix tuning / prompt tuning catastrophic forgetting RAG vs. fine-tuning decision
Tier 3 — How LLMs Respond (Inference & Prompting)

The day-to-day engineering layer — what most Applied AI roles live in.

Decoding & Sampling

temperature top-p (nucleus sampling) top-k greedy / beam search speculative decoding logprobs

Prompting Techniques

chain-of-thought (CoT) few-shot prompting zero-shot self-consistency / majority vote ReAct (Reason + Act) structured output (JSON schema) "lost in the middle"

Context Engineering

prompt caching ← you are here context window management context compaction / summarization semantic caching conversation history strategies
Tier 4 — How LLMs Ship (Systems & Production)

The "have you actually deployed this" questions. Separates engineers from practitioners.

RAG

RAG pipeline (ingest → chunk → embed → retrieve → generate) dense vs. sparse retrieval (DPR vs. BM25) chunking strategies re-ranking (cross-encoder) HNSW / vector index types hybrid retrieval + RRF RAG triad (relevance, faithfulness, answer) agentic RAG

Agents & Tool Use

function calling / tool use ReAct loop MCP (Model Context Protocol) multi-agent orchestration agent memory (short vs. long term) compounding error in long tasks human-in-the-loop triggers

Serving & Cost

TTFT vs. inter-token latency continuous batching PagedAttention / vLLM speculative decoding quantization (INT8, INT4, GPTQ, AWQ) model routing / tiered selection streaming for perceived latency input vs. output token cost asymmetry

Evaluation

LLM-as-judge Ragas (RAG-specific metrics) pass@k judge failure modes (position bias, verbosity bias) eval-driven development benchmark contamination A/B testing for LLM features

Safety & Security

hallucination causes and mitigation prompt injection jailbreaking guardrails (input + output filtering) OWASP LLM Top 10 red-teaming
